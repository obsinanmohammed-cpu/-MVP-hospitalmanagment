"# Hospital System (Java)

A simple Java console application that models a hospital management system using object-oriented design.

## What this project shows

- A main program entry point in `src/Main.java`
- Hospital domain models in `src/model/`:
  - `Person`, `Patient`, `Doctor`, `GeneralPractitioner`, `Surgeon`, `Appointment`
- Business logic in `src/service/Hospital.java`
- Input handling in `src/util/InputHelper.java`

## Features

- create and manage patients, doctors, and appointments
- support for different doctor types and appointment scheduling
- organized with inheritance and service-layer structure

## Why it is useful

This repository is ideal for demonstrating Java fundamentals in a real-world-style application:
- class inheritance
- encapsulation
- object modeling
- simple user interaction
